# messiasfms.dev

Personal portfolio of Felipe Messias — AI Engineer & Fullstack Developer, co-founder of FP Solutions.

## Stack

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind CSS v4 · Motion · WebGL (raw, no framework)

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check
- `npm run lint` — ESLint
